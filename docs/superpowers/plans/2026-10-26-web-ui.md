# vid-snatch 網頁介面 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 使用者雙擊啟動腳本後，在瀏覽器裡貼 YouTube 網址、選 MP3 / 去人聲 / MP4、看進度、完成後在 Finder / 檔案總管看到檔案，全程不看終端機。

**Architecture:** `vid_snatch.py` 拆成套件：`core.py`（下載 / 分離，吃 progress callback、丟自訂例外）、`errors.py`（例外 → 中文）、`jobs.py`（單 worker 佇列 + 事件）、`hostactions.py`（宿主端動作佇列 + 心跳）、`web.py`（FastAPI + SSE + 單頁 HTML）、`cli.py`（原 CLI，加 `--web`）。宿主機啟動腳本（bash / PowerShell）負責 Docker、pull GHCR 映像檔、開瀏覽器，然後進入每秒輪詢 `/api/host-actions` 的助手迴圈，代容器執行 reveal / pick_folder / shutdown / rebuild / uninstall。

**Tech Stack:** Python 3.12、FastAPI、uvicorn、sse-starlette、yt-dlp、demucs（`demucs.api`）、vanilla HTML/JS、Docker buildx multi-arch、GitHub Actions → GHCR、bash、PowerShell。

**Spec:** `docs/superpowers/specs/2026-10-26-web-ui-design.md`

## Global Constraints

- `requires-python = ">=3.10"`；容器用 `python:3.12-slim`。本機開發用 `uv venv --python 3.12 .venv`。
- 前端不得有 build step：單一 `vid_snatch/static/index.html`，CSS/JS 內嵌，無框架。
- 既有 CLI 用法 `docker run --rm -it -v ... vid-snatch "URL" [--video|--no-vocals] [-o DIR]` 行為不變。
- 介面文案一律繁體中文；錯誤訊息對照表以 spec 5.4 為準，逐字使用。
- 預設 port `8080`；容器內 server bind `0.0.0.0:8080`。
- 心跳：容器連續 **15 秒** 沒收到 `GET /api/host-actions` 就自行結束；啟動後前 **60 秒** 為寬限期不檢查。
- yt-dlp 背景更新逾時 **30 秒**；「YouTube 改版」類錯誤同步更新後只重試 **一次**。
- Demucs 模型 `htdemucs`，checkpoint 由 Dockerfile 以 curl 預載到 `/root/.cache/torch/hub/checkpoints/955717e8-8726e21a.th`，來源 `https://dl.fbaipublicfiles.com/demucs/hybrid_transformer/955717e8-8726e21a.th`。
- MP3 bitrate 192k；去人聲輸出檔名 `<原檔名>_no_vocals.mp3`。
- 單 worker：一次只跑一個工作，其餘排隊。
- 容器環境變數：`VS_OUTPUT_DIR`（預設 `/app/output`）、`VS_CONFIG_DIR`（預設 `/app/config`）、`VS_HOST_OUTPUT_DIR`（宿主機的輸出路徑，啟動腳本傳入，用來組 reveal 路徑）。
- 設定檔格式維持 `output_dir=<path>` 一行，檔案在 `$VS_CONFIG_DIR/config`。
- 所有 `POST /api/*` 必須帶 header `X-Vid-Snatch: 1`，否則 403（localhost CSRF 防護，我的決定）。
- GHCR 映像檔 `ghcr.io/irene-chou/vid-snatch`，tag `latest` + commit SHA，平台 `linux/amd64,linux/arm64`。
- macOS 與 Windows 都要實機驗收。

## Review Focus

1. 貼上的網址前後有空白、或整段是全形字元 → 要 trim 後再驗證，不能因為一個空白就標紅。（測試在 Task 2）
2. 自訂檔名清完非法字元後是空字串（例如只打了 `???`）→ 回退用 `video`，不能產生空檔名。（測試在 Task 1）
3. 一次貼三個網址但兩部影片標題相同 → 第二個自動變 `標題 (1)`，不能互相覆蓋。（測試在 Task 6）
4. 使用者按「選擇資料夾」後在原生視窗按取消 → 設定不變，API 回原路徑，不能把空字串寫進設定檔。（測試在 Task 8）
5. 頁面重新整理後 → `GET /api/jobs` 必須回傳進行中工作的目前步驟與百分比，否則卡片會停在 0%。（測試在 Task 8）

### Task 6: 工作佇列

**Files:**
- Create: `vid_snatch/jobs.py`
- Test: `tests/test_jobs.py`

**Interfaces:**
- Consumes: Task 4 的 core 函式簽名、Task 3 的 `translate`。
- Produces:
  - `MODES = {"mp3": ["取得資訊", "下載", "轉檔"], "mp4": ["取得資訊", "下載", "合併"], "no_vocals": ["取得資訊", "下載", "轉檔", "分離人聲"]}`
  - `@dataclass class Job: id: str; url: str; mode: str; filename: str | None; overwrite: bool; state: str ("queued"|"running"|"done"|"failed"); step: int; step_total: int; step_name: str; percent: float | None; message: str; detail: str; result_path: str | None; error_kind: str | None`，`to_dict()`。
  - `class Backend(Protocol)`：`fetch_title`、`download_audio`、`download_video`、`remove_vocals`、`update_ytdlp`，簽名同 core（測試用 fake 注入）。
  - `class JobQueue:`
    - `__init__(self, output_dir: Path, backend: Backend = core)`；`self.backend` 為公開屬性（測試會改它）
    - `add(self, url: str, mode: str, filename: str | None = None, overwrite: bool = False) -> Job`
    - `list(self) -> list[Job]`
    - `get(self, job_id: str) -> Job | None`
    - `retry(self, job_id: str) -> Job`（複製失敗工作重新排隊）
    - `subscribe(self) -> queue.Queue[dict]`、`unsubscribe(self, q)`：每次 job 欄位變動就 put `job.to_dict()`
    - `start(self)` / `stop(self)`：單一 daemon worker thread
    - `exists(self, filename: str, mode: str) -> tuple[bool, str]`：目標檔是否存在、以及 `unique_path` 建議的檔名（不含副檔名）
  - 執行規則：`filename` 為 `None` 時用 `sanitize_filename(fetch_title())`；`overwrite=False` 且目標存在時用 `unique_path`；`no_vocals` 模式下載 wav 後呼叫 `remove_vocals`，最後刪 wav；錯誤 `kind == "extractor_outdated"` 時呼叫 `backend.update_ytdlp()` 後重跑一次，仍失敗才 `failed`。
  - 目標檔名規則：`mp3` → `<name>.mp3`、`mp4` → `<name>.mp4`、`no_vocals` → `<name>_no_vocals.mp3`。
  - 步驟推進：開始時 `step=1`「取得資訊」；呼叫下載前 `step=2`；yt-dlp hook `status == "finished"` 時 `step=3`（轉檔 / 合併）；`no_vocals` 呼叫 `remove_vocals` 前 `step=4`。完成時一律 `step = step_total`、`percent = 100.0`、`state = "done"`。

def run_until_idle(q, timeout=5):
    deadline = threading.Event()
    for _ in range(int(timeout * 20)):
        if all(j.state in ("done", "failed") for j in q.list()): return
        deadline.wait(0.05)
    raise AssertionError("queue did not drain")

### Task 7: 宿主端動作佇列與心跳

**Files:**
- Create: `vid_snatch/hostactions.py`
- Test: `tests/test_hostactions.py`

**Interfaces:**
- Produces:
  - `class HostActionQueue:`
    - `push(self, kind: str, payload: dict | None = None) -> str`（回 action id）
    - `poll(self) -> list[dict]`：回傳所有尚未送出的動作 `{"id", "kind", "payload"}`，標記已送出，並更新 `last_heartbeat = time.monotonic()`
    - `set_result(self, action_id: str, result: dict | None) -> None`
    - `wait_result(self, action_id: str, timeout: float) -> dict | None`（逾時回 `None`）
    - `last_heartbeat: float | None`（從未收到為 `None`）
    - `heartbeat_lost(self, now: float, grace: float = 60, limit: float = 15) -> bool`：`started_at` 之後未滿 `grace` 秒永遠 `False`；之後若 `last_heartbeat is None` 或 `now - last_heartbeat > limit` 為 `True`。
    - `__init__(self, started_at: float, clock: Callable[[], float] = time.monotonic)`：`poll()` 用 `clock()` 記心跳，測試注入假時鐘。

from vid_snatch.hostactions import HostActionQueue

def test_push_poll_once():
    h = HostActionQueue(started_at=0.0)
    aid = h.push("reveal", {"path": "/x"})
    assert h.poll() == [{"id": aid, "kind": "reveal", "payload": {"path": "/x"}}]
    assert h.poll() == []
    assert h.last_heartbeat is not None

def test_wait_result():
    h = HostActionQueue(started_at=0.0)
    aid = h.push("pick_folder")
    threading.Timer(0.1, lambda: h.set_result(aid, {"path": "/picked"})).start()
    assert h.wait_result(aid, timeout=2) == {"path": "/picked"}
    assert h.wait_result("nope", timeout=0.1) is None

def test_heartbeat_grace_then_limit():
    now = {"t": 1000.0}
    h = HostActionQueue(started_at=1000.0, clock=lambda: now["t"])
    assert h.heartbeat_lost(now=1030.0) is False      # 寬限期內
    assert h.heartbeat_lost(now=1061.0) is True       # 過寬限、從未收到
    now["t"] = 1070.0; h.poll()                        # 收到心跳
    assert h.last_heartbeat == 1070.0
    assert h.heartbeat_lost(now=1080.0) is False
    assert h.heartbeat_lost(now=1086.0) is True

  - `pick_folder` → `osascript -e 'POSIX path of (choose folder)'`，取消時回 `{"path": null}`；`curl -X POST -H 'X-Vid-Snatch: 1' -H 'Content-Type: application/json' -d ... /api/host-actions/$id/result`

  - `rebuild` → `docker stop $CONTAINER; docker rmi $IMAGE_LOCAL; ensure_image; start_or_attach; wait_health; open_browser`
  - `uninstall` → `docker stop`、`docker rmi $IMAGE_LOCAL $IMAGE_REMOTE`、`rm -rf $CONFIG_DIR`、`delete_downloads` 為 true 時 `rm -rf "$OUTPUT_DIR"`、印完成訊息與專案路徑、`exit 0`
